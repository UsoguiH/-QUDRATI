0 — Three picks, on the real path chosen as product decisions, not decoration

Each phone is unit 1 as it is today: its real lessons and their real short-lesson counts (8, 7, 6, 6, 6), two finished, the third under way. Every shape plays the same three moments: press opens the lesson card, a lesson pops the node and throws sparkles every single time (an 8-lesson node pays out 8 times), flip turns the glyph on its axis. Tap the node itself, too.

My recommendation: the answer bubble. It is the only one of the three that says «GAT» and not just «maths», which is what makes a student who has never heard of us trust the app at first sight. It costs no more than the others, and a half-shaded bubble is the strongest reason to come back tomorrow. If you want the least risk, the fraction is the fallback: it changes the least for students already using the app.

1 — Duolingo's node played from their file, frame for frame

One Rive file draws the node, its icon, the ring of lessons around it and every transition between them; the app only flips inputs. Each card restarts the file in the starting state and flips the same inputs at the same moments.

The icon inside the node (from_icon_num / to_icon_num, with icon_anim_bool on)

The colours (color_num: one per character's unit; 0 is locked)

What this shows about their system: the node never changes shape. Every state (locked, current, done, legendary, skipped) is the same 3D coin with a new colour or icon, and every event is a squash, a hop, a flip or a ring segment filling. The ring around the current node is the lesson count: one segment per lesson, and finishing a lesson fills the next segment. The node only jumps and changes when the last segment fills.

2 — Ten shapes for Qudrati not a coin: a maths object

The same three moments in each: press, finish a short lesson, finish the node (the next one opens). The colours and glyphs are the app's own. Each shape carries the node's lesson count in the shape itself, so nothing has to be added around it. Tap a node to press it.

3 — Eight more ideas, built the same three moments on each

The balance, the puzzle, the honeycomb, the ruler, the calculator key, the gem, the graph and the star polygon. Each has press & open, a pop with sparkles for every lesson, the flip, and the whole node finishing into gold.
